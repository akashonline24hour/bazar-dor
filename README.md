# 🛒 বাজার দর (BazarDor)

বাজার দর (BazarDor) হলো প্রতিদিনের বাজার পণ্যের সঠিক ও হালনাগাদ দাম পর্যবেক্ষণ ও ট্র্যাক করার একটি আধুনিক ওয়েব অ্যাপ্লিকেশন। সাধারণ ব্যবহারকারীরা সহজেই দৈনন্দিন নিত্যপ্রয়োজনীয় জিনিসের বাজার দর জানতে পারবেন এবং ডাইনামিক বাংলা তারিখের সাথে সাম্প্রতিক মূল্যের তথ্য দেখতে পাবেন।

---

## 🛠️ Technologies Used

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Frontend & UI:** [React](https://react.dev/), [Tailwind CSS](https://tailwindcss.com/), [daisyUI](https://daisyui.com/)
- **Authentication:** [Better Auth](https://www.better-auth.com/) (Google & GitHub Social Login)
- **Database:** [MongoDB](https://www.mongodb.com/) (Mongoose)
- **Deployment:** [Vercel](https://vercel.app/)

---

## ✨ Key Features

1. **📊 Real-time Commodity Pricing:** নিত্যপ্রয়োজনীয় পণ্যের সাম্প্রতিক দাম এবং ক্যাটাগরি অনুযায়ী সাজানো তালিকা দেখার সুবিধা।
2. **🔐 Social Authentication:** Better Auth ব্যবহার করে Google এবং GitHub অ্যাকাউন্টের মাধ্যমে দ্রুত ও নিরাপদ সোশ্যাল লগইন/সাইনআপ ব্যবস্থা।
3. **📅 Dynamic Bangla Date Integration:** ইংরেজি তারিখের সাথে সাথে স্বয়ংক্রিয়ভাবে সঠিক বাংলা তারিখ ও বর্ষ দেখার রিয়েল-টাইম ফিচার।
4. **📱 Responsive & Clean UI:** Tailwind CSS এবং daisyUI দ্বারা তৈরি ব্যবহারকারী বান্ধব ও সকল ডিভাইসে (মোবাইল, ট্যাবলেট, ডেস্কটপ) সুন্দরভাবে প্রদর্শিত ইন্টারফেস।
5. **⚡ Fast & Optimized Performance:** Next.js Server Components এবং MongoDB-এর সেরা অনুশীলনের মাধ্যমে দ্রুত ডাটা লোডিং এবং মসৃণ পারফরম্যান্স।
